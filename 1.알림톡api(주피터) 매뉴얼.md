# 1. 호출 API

## 1.1 Host

>> https://jupiter.lunasoft.co.kr

## 1.2 Request
- path: /api/alimtalk/message/send
- method: post
- header:  Content-type: application/json
- body: 1.2.1 Payload 참고

### 1.2.1 Payload (json object)
|이름|타입|필수|설명|예제|
|--|--|--|--|--|
|userid |text(20) |Y |사용자 ID |"userid":"lunasoft"|
|api_key |text(50) |Y |Api_key|"api_key":"key_1234" |
|template_id |number |Y |플러스 친구 템플릿 ID |"template_id":30001 |
|messages| json array |Y |메시지 정보 (최대 1000개) |"messages": [1.2.2 Message(json 참고)]|

### 1.2.2 Message (json array)
|이름|타입|필수|설명|예제|
|--|--|--|--|--|
|no |text(20)| Y |메시지 번호 |"no":"0"|
|tel_num |text(20) |Y |받는 이 전화번호 |"tel_num":"01012345678" |
|reserve_time| text| N |예약 발송 시 발송 시간 |"reserve_time":"2019-06-01 00:00:00"|
|custom_key| text(40) |N |알림톡/SMS/LMS 성공 실패 </br>여부 확인 시 unique key </br>**※ Webhook url을 블룸에이아이에 선등록 해주셔야 합니다.**|"custom_key":"a1234"|
|msg_content text(1000) Y |메시지 내용 </br>(최대 1300자) |"msg_content":"안녕하세요.알림톡입니다."|
|sms_content text(1000) Y |메시지 내용  </br>(최대 ksc5601기준 2000byte) |"sms_content":"안녕하세요.문자메세지입니다"|
|use_sms |text(1)| Y |실패시 sms 전송여부 |1 : 전송 0 : 미전송 |"use_sms":"1"|
|app_user_id| text(50)| N | tel_num 혹은 app_user_id </br>둘 중 하나는 반드시 있어야 </br>합니다. </br>tel_num 와 app_user_id의 </br>정보가 동시에 요청된 경우 </br>tel_num 로만 발송합니다.| "app_user_id" : "12345"| 
|carrier_code| text(2)| N|택배사 코드 </br>(2.3 택배사 코드 참고) </br>**※ 배송조회 템플릿ID인 경우 필수입니다.** |"carrier_code" : "1"|
|invoice_number| text(30) |N |운송장 번호 </br>**※ 배송조회 템플릿ID인 경우 필수입니다.**|"invoice_number" : "123456789"|
|price |number |N |메시지 내 포함된 금액 정보 |"price" : 75000|
|currency_code |text(3)| N| 통화 코드 (메시지 내 포함 된 금액 정보) </br>**※ KRW, USD, EUR**|"currency_code":"KRW"|
|title |text(50)| N| 강조 내용 </br>**※ 강조유형 템플릿ID인 경우 필수입니다.**|"title" : "CJ택배 1234567"|
|btn_url |json array|N|버튼 URL|"btn_url" : [{1.2.3 Button Url 참고 }]|

## sms_content 의 경우 90byte가 넘을 경우 msg_content가 MMS로 전송됩니다. 
## 배송조회 템플릿 사용 시 사전에 ‘블룸에이아이’ 운영팀을 통해 추가 설정이 필요함으로 문의 부탁드립니다.


### 1.2.3 Button Url
|이름|타입|필수|설명|예제|
|--|--|--|--|--|
|url_pc |text(100) |N |pc 버튼 URL |"url_pc":"https://ww.lunasoft.co.kr" |
|url_mobile |text(100) |N |mobile 버튼 URL |"url_mobile":"https://ww.lunasoft.co.kr/m"|
|scheme_android |text(100) |N |Android 앱 링크 URL |"scheme_android":"lunaapps://open" |
|scheme_ios |text(100) |N |IOS 앱 링크 URL |"scheme_ios":"lunaapps://open" |
|map_address |text  |N |지도버튼 주소 |"map_address":"서울 중구 서소문로 89" |
|tel_number |text  |N |전화 링크 버튼 |"tel_number":"01012345678" |

## 1.3 Response
|이름|타입|필수|설명|예제|
|--|--|--|--|--|
|code |number| Y |처리 결과 코드 </br>(0 : 정상 / 나머지는 오류) |"code ":0|
|msg |json| N| 오류 메시지</br>(오류시 존재하는 값) "msg ": { 1.3.1 Msg 참고 }|

### 1.3.1 Msg
|이름|타입|필수|설명|예제|
|--|--|--|--|--|
|userid |text(20)| Y| 사용자 ID |"userid":"lunasoft"|
|requested_at| text| Y |요청된 시각| "requested_at":"2019-06-01 00:00:00"|
|messages| json array| Y| 건별 오류 정보 |"messages" : [{ 1.3.2 Messages 참고 }]|

### 1.3.2 Messages
|이름|타입|필수|설명|예제|
|--|--|--|--|--|
|no| text(20)| Y |메시지 번호 |"no":"0"|
|tel_num |text(20)| Y| 받는 이 전화번호 |"tel_num":"01012345678"|
|result_code |number |Y |해당 건 오류 코드 |"result_code" : 2005|
|result_msg |text(200)| Y| 해당 건 오류 메시지| "result_msg": "[2009] messages.tel_num의 번호가 유효하지 않습니다."|


### 1.3.3 Example

- 성공
```json
{ 
  "code": 0, 
  "msg": null 
} 
```

```json

  "status": 400,
  "errors": {
    "Messages": [
      "messages 가 필요합니다."
    ]
  },

}
```
